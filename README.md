# README
The Cape Verde Circulation and Tide model (CVCTM) set up with run-time parameters and data processing scripts.

# /Spin_up
CVCTM spin-up run during 2011-2013, including wind- and buoyancy-forced processes, but not tidal forcing.
# /2014, 2015, 2016
CVCTM standard run, considering both realistic stratification and wind-forced processes under tidal open boundary conditions.
# /CVCM
A twin run for model year 2014 with identical parameterization and wind forcing, but excluding tidal forcing.
# /ob & /ini & /Forcing
The pre-process scripts for open boundary conditions (ob), initial fields (ini), and surface forcing fields (Forcing)
# Model_info
The Python package for pre-processing scripts
# /Grid & /postprocess
The scripts for post-processing analysis
